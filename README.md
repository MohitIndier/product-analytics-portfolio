# product-analytics-portfolio

Product Analytics case studies built as part of my journey to get better at Product Analytics. Each project includes the 
problem statement, SQL analysis, findings, and product recommendations.

## Projects

### 1. [UPI Payment Funnel Analysis](./upi-funnel-analysis)
Analyzed a simulated 50K+ transaction dataset to identify where UPI payments 
drop off in the funnel, which banks have the highest backend failure rates, 
and whether a retry mechanism could recover failed transactions.
**Key finding:** PNB/BOB fail at ~2.5x the rate of top-performing banks; 
auto-retry logic could recover 96% of transient failures.
